# Contributing

Thanks for your interest. This profile repository is maintained by
**Pankaj Mehta (@procatesoft)**.

## Reporting an issue

Open an issue using the provided templates. Please include enough detail to
reproduce the problem (browser/OS, steps, screenshots).

## Suggesting a change

1. Fork the repository.
2. Create a topic branch: `git checkout -b feat/short-description`
3. Make the change with a clear, conventional commit message
   (`feat:`, `fix:`, `docs:`, `chore:`).
4. Open a pull request describing **what** and **why**.

## Style

- Markdown: one sentence per line where practical, no trailing whitespace.
- Keep the profile README readable in both light and dark themes.
- Do not add third-party images that are likely to disappear.
